# Online Flight Booking System (OFBS)

## Project Overview
A complete web-based Flight Booking System built with PHP and MySQL. Users can search flights, book tickets, submit passenger details, process payments, view e-tickets, and submit feedback. Admins can manage flights, airlines, passengers, and bookings.
